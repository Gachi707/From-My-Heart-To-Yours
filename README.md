# From My Heart to Yours

Write a love letter in an old notebook style and send it as a private link.

**Live site:** https://gachi707.github.io/From-My-Heart-To-Yours/

## Features
- Notebook-page design in maroon and baby pink
- Six text styles: Classic, Signature, Editor, Typewriter, Elegant, Literature
- Date, To and From fields
- Optional faded photo of the recipient
- Autosaved drafts on your own device
- Share link that carries the letter, with no server or account
- Reply, print and phone-friendly layout

## How privacy works
Letters are never uploaded. The letter is packed into the part of the link
after the `#`, which browsers don't send to any server. Anyone who has the
link can read the letter, so share it privately.

## Built with
HTML, CSS and JavaScript, using Git, GitHub and VS Code.
